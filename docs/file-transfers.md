# 单文件 SFTP 传输

服务器列表的文件夹图标打开文件窗口，提供远端浏览、文件设置和传输记录。直连、单层 SSH 跳板及 SOCKS5 共用既有主机验证和 OperationService；不执行 scp 或远端脚本，不自动提权。

## 文件设置

每台服务器的文件设置对其所有授权接入生效：

- 允许上传文件：默认关闭。
- 固定上传目录：启用上传时填写一个远端绝对目录，目录应已存在。客户端只能给出单个目标文件名，不能改变目录。
- 单文件大小上限：上传和下载共用，默认500 MiB，可设1–10240 MiB。
- 上传校验方式：默认标准校验；可选完整读回SHA-256比对。
- 持续无进展时限：默认120秒，可设30–3600秒；仅字节推进或阶段切换重置，不通过状态轮询延长。
- 文件任务总时长：默认120分钟，可设1–1440分钟，包含准备快照、传输、校验和发布；不包含审批等待与独立SSH连接时限。

不再配置本机发送/接收目录或远端读取根；上传/下载自动执行由全局审批模式各自的勾选项控制。旧的路径授权和自动传输数据不会继承，新版上传需重新设置。旧记录保留作历史，新版不派发旧格式待审批请求。

## 每次请求与审批

智能体使用自己的本机文件能力选择路径，再交给 HostHarbor 传输。既有本机文件权限不替代 HostHarbor 的本次审批。

上传提供服务器ID、本机绝对文件路径及目标文件名。审批前只查询本机文件元数据，绑定完整源/目标路径、文件大小、修改/身份信息、设置版本和大小上限；人工批准或策略授权自动执行后才读取内容。无需事先将文件移动到某个发送目录。

下载提供服务器ID、远端文件路径和本机完整保存路径，不必预先列目录或配置读取根。派发时查询源大小，超出设置即停止；可附带已知size/mtime以绑定历史列表条目。审批前未知大小会明确标注“批准后查询，超出上限不传输”。本机父目录需已存在，智能体可通过自己的本机文件能力准备目录。

每种审批模式分别保存“上传文件需要审批”和“下载文件需要审批”，旧数据两项均默认勾选；在模式卡片下方的文件传输审批区域设置当前模式。取消某项后该方向自动执行并记录，仍校验路径、固定上传目录、大小、授权与主机。暂停执行始终拒绝新请求。修改策略使所有未派发请求失效，不自动批准已有待审批记录。目录浏览只查元数据，直接返回列表，不创建审批或操作记录；即使全部审批模式也不要求目录审批，暂停仍拒绝访问。仍检查服务器接入范围、到期/撤销、锁定、主机指纹，不读取文件内容。审批中心和文件页均可批准/拒绝/取消，只有上传/下载进入操作日志，目录浏览不进入。

设置更改会作废本服务器所有接入的未派发文件任务，并请求中断活动连接。锁定、授权撤销/到期、凭证或主机配置改变仍执行原访问复查。仅锁定桌面并保留后台MCP时，已授权后台任务遵循原设定；人工审批仍需解锁。

## MCP（文件四工具，总计12工具）

| 工具 | 请求与返回 |
| --- | --- |
| get_file_access | 返回uploadEnabled、uploadDirectory、maxFileSizeMiB、verification、idleTimeoutSeconds、totalTimeoutMinutes、revision、uploadRequiresApproval、downloadRequiresApproval及uploadsPaused/downloadsPaused |
| list_remote_files | remotePath、offset，直接返回entries/nextOffset，无操作ID、审批、记录或轮询 |
| upload_file | localPath为本机绝对文件路径，remoteName为固定上传目录内单个文件名 |
| download_file | remotePath和localPath，可选expectedSize/expectedMtime，无需先列目录 |

移除list_local_files。没有通过MCP枚举本机文件或传输Base64内容的接口。上传请求不接受remotePath；下载不接受旧localName。刷新客户端MCP工具定义后使用新参数。

上传/下载任务保留requestKey去重和原操作ID续接，三分钟等待提示、五分钟审批有效期保持。设置变化后重复原请求仍查询原记录，不会换到新目录自动重传。传输记录提供20/50/100条分页、上传/下载筛选，点击详情看完整路径、进度和审批；旧浏览记录不在传输列表中。fileResult记录准备/传输/校验字节数、阶段开始与累计耗时、校验方式和结果、SHA256及发布状态和必要的临时文件线索，不必read_output。

## 完整性与限制

- 上传获人工或策略授权后复查源身份/大小/修改时间，生成私有临时快照并核对读取前后元数据；网络上传使用快照，结束清理。源在审批后变化会停止，快照建立后源再变化不会改变本次传输字节。临时内容不进入数据库，但依赖本机文件系统权限，并非凭证库加密文件。
- 上传写远端同目录随机.part，标准校验核对源快照与发送字节哈希、服务器确认写入的字节数、成功关闭及远端普通文件大小，不下载整份临时文件。标准模式的SHA-256仅表示发送字节，不证明远端内容哈希相同。完整校验额外通过SFTP读回临时文件，按序计算SHA-256与源比对，检查读取前后大小/mtime；会增加一次完整下载的流量和耗时。校验通过后使用标准SFTP v3不覆盖RENAME发布；信任已认证服务器正确实现该协议，不调用覆盖扩展。
- 下载经lstat/realpath/fstat拒绝符号链接，绑定读取开始时大小/mtime，结束复查并核对字节数；临时文件sync后以同目录hard-link不覆盖发布。接收文件系统需支持硬链接，失败不降级覆盖。摘要是实际接收字节的哈希，不是独立源端签名；元数据不证明完整远端快照。
- 文件均不覆盖、不执行、不解压，无递归、同步、远端复制或断点续传。文件任务使用独立无进展与总时限，目录查询仍30秒/100项分页、最多扫描10000项。收发及完整读回最多4个64KiB分块在途，按偏移收发、按顺序计算哈希，批次失败等待当前请求结束后停止调度，内存有界。内容，不进入MCP文本/SQLite/终端回放。
- 私有快照最多为每活动任务配置的文件上限（最多4个活动任务），崩溃残留下次上传前清理。配置较大上限时应准备本机和远端空间；日志的七天回放保留及密文配额不管理这些用户文件。
- 中断可能保留.part，取消/超时不证明远端操作停止。记录未知结果和临时线索，不自动删除、重试或通过换名绕过审批。清理操作日志不删除传输文件。

本机父目录在请求时规范化，文件名拒绝穿越、分隔符、Windows保留名；执行前再次检查目录和普通文件，拒绝文件符号链接。每次审批授权具体路径，不宣称限制已控制当前账号的进程或消除文件系统竞争。远端路径检查同样不是服务器文件系统沙箱。

## 验证

隔离合成SSH/SFTP验证双向二进制、哈希、按次审批、固定目录、大小上限、版本作废、无覆盖、符号链接、源变化、取消、跳板/SOCKS5及旧数据不继承。原生和界面结果见执行计划。本批只本地迭代，不推送GitHub、不触发Actions；未访问真实服务器。Windows物理GUI仍待验收。


## 传输失败诊断

新记录保存准备、临时文件打开、传输、校验、最终发布阶段及固定错误码/数字SFTP状态。权限不足、路径不存在、不支持操作会明确提示。未尝试最终rename/link发布的失败标记执行失败，但仍可能留有临时文件或在途写入；不代表临时数据已清理。发布请求发出后无法确认结果仍为结果未知，不自动重传。旧记录没有这些阶段标记时不追溯推断，不能从旧通用错误恢复真实SFTP原因。

## 大文件进度与兼容

绿色进度条按当前阶段显示；传输字节达到100%不代表校验或发布完成，智能体以succeeded及published为准。完整校验显示独立读回进度，标准校验显示元数据检查。FILE_IDLE_TIMEOUT表示持续无进展；FILE_TOTAL_TIMEOUT表示达到总时长。保留原操作ID、阶段和临时文件线索，不自动重传或变更旧失败记录。

旧服务器设置缺失新字段时采用标准校验、120秒无进展和120分钟总时限。已创建的旧任务快照缺失新字段时保留完整读回及原任务总时限，不追溯改变审批。新任务把方式和时限绑定到审批快照；设置修改仍作废未派发任务并中断活动任务。桌面文件窗口在可见时续期内部接入，执行到期检查重读当前有效期；不延长真实MCP接入授权，关闭窗口不再续期。
