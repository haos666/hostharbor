# Roadmap

The current release distributes macOS Intel and Apple Silicon builds. Existing functionality and limitations are described in the [README](../README.md), [changelog](../CHANGELOG.md) and [security policy](../SECURITY.md).

Next priorities:

1. Windows native acceptance before publishing Windows installers.
2. Developer ID signing and notarization when an identity is available.
3. Broader external MCP client compatibility checks.

Portable recovery/export, automated updates and resumable transfers require separate design and validation; they are not current product promises.
