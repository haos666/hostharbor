# 界面锁定与后台 MCP

系统设置 → 安全 → **锁定时暂停 MCP 访问**，默认开启。

- 开启：锁定会清除执行内核持有的凭证密钥，MCP 无法读取上下文、发起或继续执行；活动操作按既有中断/结果未知语义记录。不是远程进程已终止的保证。
- 关闭：首次输入正确密码解锁后，空闲、系统锁屏、睡眠、关闭 macOS 窗口及托盘锁定均隐藏桌面信息，已授权 MCP 可继续使用凭证。睡眠期间网络是否可用取决于操作系统。
- 后台访问仍核验接入 Token、服务器范围、有效期、撤销、主机指纹、策略及持久化执行意图。允许的查询会执行并录制；需要人工审批的请求保持待审批，需要先解锁应用，再批准，原有到期与三分钟等待指引保持。
- 锁定页明确显示后台 MCP 仍获允许；该状态表示后台凭证可用，不保证 MCP 服务已开启、网络在线或每条命令均获允许。提醒仅展示数量，不显示命令或服务器。
- 重启和执行内核重启均需要重新解锁；该选项不会自动解密凭证、自动开启 MCP 服务或自动批准请求。
- 修改密码、恢复码、恢复重设、验证失败及配置损坏后的锁定始终清除密钥；保存密码后仍需重新解锁。错误密码的解锁尝试会暂停后台访问。

关闭开关前需确认：

> 关闭后，锁定应用不会停止智能体使用已保存的凭证。服务器授权范围、有效期、审批规则和操作记录仍然生效。

后台执行内核会保留使用凭证所需的密钥；界面锁定不表示密钥已被清除，也不防御已控制当前系统账号的进程。退出应用可以停止本地后台访问，但不证明远端已派发进程停止。Windows 关闭最后一个窗口仍退出。

## 实现与验证

Core 的 DesktopSession 独立管理桌面会话；桌面 RPC 默认拒绝锁定状态，包含凭证、服务器、档案、日志、接入 Token 导出及人工审批。异步结果在返回时复查会话版本。MCP 不经过桌面门禁，但仍必须通过真实凭证库和统一 OperationService；没有绕过真实 vault 锁定。

`mcp-lock-settings.json` 只包含 revision/pauseMcp，严格类型、版本冲突校验和原子替换；改动需要已解锁桌面，关闭另需确认。该本机设置文件不被视为防同用户篡改的安全边界。Main 保留锁定版本校验，初次解锁与后台会话恢复分开：后者验证密码和已有密钥，不清除密钥、不取消后台任务。

合成单元与原生验收结果见执行计划；不使用真实凭证、服务器或模型调用。
