# 常见排障查询验收范围

本轮为 #56，基于可组合查询引擎补齐完整排障路径。辅助审批无需开启 AI，不改变用户保存的模式；精确自定义审批/拒绝规则始终有效。

能力按语法、工具子命令、参数和对象共同定义。下面是已实现范围；不是任意 Shell 的只读判定，也不把没有危险关键词当作授权。

| 场景 | 自动查询范围 | 保留人工的边界 |
| --- | --- | --- |
| 系统状态 | uname/date/uptime/hostname、lscpu/free/getconf、有限 vmstat、资源 proc 文件 | 设置时间/主机名、持续采样、任意 proc 内容 |
| 进程与网络 | ps 列表/登记字段/PID/排序、有限批处理 top、ss 查询、ip 地址/路由/链路/邻居列表 | kill/ss杀连接、ip增删改、提权或交互模式 |
| 磁盘与目录 | lsblk登记字段、df/du、字面路径 ls/stat/readlink/realpath、深度1..3的find元数据条件 | 外部格式文件、find执行/删除、文件写入；元数据权限不授予内容读取 |
| 程序版本 | nginx/apache/httpd、Node/Python/Java/PHP/Ruby、MySQL/PostgreSQL/Redis、git/go/docker/curl/openssl的已登记版本参数 | 任意程序 --version、临时目录程序、脚本、模块或启动/重载参数 |
| 日志 | /var/log 系统日志（含认证运行日志）、部署根下 log/logs/logfiles 的常见日志、具体桌面维护文件入口 | 私钥、凭证/密码文件、.env及伪装后缀、任意未授权文件、tail跟随模式 |
| HTTP | loopback或当前SSH服务器主机的HEAD；固定 /、health、healthz、ready、readyz、status、ping、version、metrics 路径GET | 其他主机、URL凭证/查询串、自定义头/认证/cookie、配置、上传、代理、跳转、-k、文件输出（/dev/null除外） |
| TLS | 限定上述目标的有限握手、公开证书链；openssl x509登记证书路径或上游证书输入的元数据字段 | 客户端密钥/会话/密钥日志文件、其他主机、任意网络应用输入、写入证书 |
| 文本和组合 | grep/head/tail/cut/sort/uniq/wc；awk字段输出、sed数字行截取；字面echo/printf、命令定位、有限timeout | 通用脚本/表达式执行、外部模式/程序、输入展开、未登记参数 |

## 路径与入口

相对路径按本次不可变 `cwd` 做 POSIX 词法解析；重建命令仍在该目录执行，不存在跨请求cd状态。元数据查询可以指向字面路径；文件内容必须属于登记系统文件、操作日志命名空间或确切已维护入口。AI报告本身不增加文件权限。具体桌面维护的file入口来自当前服务器的ApplicationRecord；连接配置发生变化的记录不提供入口。

使用维护入口的普通cat/tail/grep等请求，将应用版本集合摘要保存在queryPlan.scopeRevision中。启动/预览/人工批准/派发均重新计算，入口移除、应用或连接版本改变时，旧请求不能按新权限派发。客户端不能传入queryScope或自行标记已验证。摘要不替代服务器授权、主机验证和执行意图持久化。

cat保留读取完整文件的含义，未改写成末尾样本。大日志可能触及现有输出配额/时限；建议明确tail/head或使用query_application_logs。读取样本、空结果或结果未知均不能证明服务没有报错，也不能自动重跑未知请求。

## 网络配方

curl重建时固定首参数-q，忽略curlrc；禁用代理和跳转，不使用netrc/认证头。显式校验一个URL、GET/HEAD方法和写出格式，拒绝格式文件 `-w @<path>` 及文件写出指令。限定最多10秒、连接最多5秒、内容最多256 KiB；用户请求更短时保留更短上限。默认GET只允许表中固定健康路径，HEAD可查看目标的其他无查询串路径响应头。不发送请求正文，不将GET等同于服务端必然零副作用。

TLS探测固定系统openssl、10秒timeout和关闭应用输入，只取握手/公开证书信息。探测不表示该证书已通过验证，不绕过SSH主机验证，也不承诺远端程序一定响应终止信号。

## 组合与误报

解析分号、换行、&&、||和管道，所有分支都必须通过，不能先执行安全片段再询问剩余片段。支持段末按原顺序保留2>&1以及stdout/stderr到/dev/null；拒绝其他文件/描述符重定向。普通空echo、固定printf标签可以独立通过。

已经完整校验的查询或结构化日志请求中，标题、搜索模式里的rm等只是数据，不再因全文关键词误报高风险。未知Shell仍使用保守风险提示并转人工；明确自定义规则不被覆盖。Core对自动查询额外检查已知敏感值，命中则保留人工且不外发AI；过滤是尽力而为，不保证识别所有秘密。

操作列表新增独立“审批”列：自动通过、人工批准/拒绝、策略拒绝、待审批、未批准、未记录。执行成功/失败/未知与审批方式分别展示；旧记录不推测审批方式。

## 验证与维护

场景源：`tests/helpers/diagnostic-cases.ts`，包含49个系统/进程/网络/版本/元数据/日志/HTTP/TLS/服务及组合场景；每个场景另测试追加修改操作时整条不派发，并有危险参数/目标/读取反例。新增支持必须同时扩展正例与反例，不要求用户为不同输出标题维护完整字符串规则。

纯语义测试检查重建Shell语法；本机SSH fixture验证实际收到重建命令；macOS原生utility Core/真实MCP SDK逐一运行全部场景（Linux工具执行由合成SSH服务拦截，不声称在真实Linux资产上验收工具安装路径）。另在本机一次性HTTP服务实际执行curl，主动注入合成curlrc及代理，确认只有HEAD请求、无认证头/cookie。

测试不连接用户服务器，不读取真实日志，不调用用户AI。Windows物理GUI仍待验收；双平台CI结果单独记录。

远端可执行文件、环境、DNS、服务语义和文件系统链接仍属于信任边界。部署路径内的已登记程序名和版本参数不是程序身份的密码学证明；权限由远端账号限制。查询工具可能写临时文件/访问时间或服务日志，元数据/日志中也可能含秘密。本功能不是远端文件沙箱或无副作用保证。
