# 共享 SOCKS5 代理（已实现）

服务器页在“管理标签”左侧提供“管理代理”。代理有名称、地址、端口，可选独立用户名及密码凭证引用。服务器编辑器选择已保存代理；密码仍由 Core 从本机凭证库取得。修改共享代理对所有引用服务器生效；引用中的代理不能删除，不会静默退回直连。

Core 将目录加密保存在 metadata `socks-proxies:v1`。服务器 route 同时保存 `proxyId` 与规范化配置快照，使既有审批快照、记录、主机校验和 SSH 路径继续使用确定的连接参数。保存服务器时以目录配置为准，拒绝不存在的引用。修改代理使用 SQLite savepoint 原子更新目录及所有关联服务器的 route / revision；配置失效通知取消未完成请求和活动连接，清除指纹挑战。代理编辑/删除使用 revision 拒绝过期表单。

首次打开服务器页时，桌面专用入口迁移旧内联 SOCKS5 配置，相同配置合并为一个共享代理；迁移是事务性的且不联网。已有内联 route 仍可读，旧备份继续可导入。目录最多 200 项，代理名称不区分大小写且唯一；使用中的密码凭证不能删除或改成私钥，即使代理尚未绑定服务器。

新加密备份携带可选代理目录，恢复时重新分配代理 ID、重映射密码凭证与服务器引用；相同连接配置复用本机代理，同名不同配置另存，不覆盖本机代理。未选择相应密码凭证且无法匹配本机凭证时，该代理不导入；引用它的服务器仍需满足凭证依赖。代理目录参与导入预览的变更检查。旧版应用不支持含新字段的备份，恢复应使用本版或更新版本。

接入服务器选择支持按名称、地址和账号搜索。“全选当前结果 / 取消当前结果”只修改可用凭证服务器的当前搜索结果；范围外的已选授权保留。无凭证、已删除的旧授权仍可单独移除，不会借批量选择新增不可用目标。
