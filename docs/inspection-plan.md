# 服务器巡检 V1

日期：2026-11-02。当前状态：V1 已完成本机实现与 macOS arm64 验收，尚未发布到 GitHub。

## 范围与流程

每台服务器一份可编辑 Markdown 手册，使用二级标题作为检查项（最多 40 项）。桌面保存与确认版本；可以从已保存档案/应用生成本地模板，或者明确同意将这些历史信息发送到已配置 AI 生成待确认草稿。不会新增 SSH 调查，重新生成先展示草稿，不覆盖已保存文档。

MCP 提供授权范围内巡检手册列表、读取指定手册及结构化报告提交。外部智能体负责定时调度；命令仍由已有操作服务审批执行，不因手册获得额外权限。报告绑定手册版本/摘要、服务器版本、检查时间、接入身份和操作证据。客户端提交的结论明确标为智能体报告，不能当作平台独立验证。

## 边界

- 正常/异常必须关联本接入、同服务器、检查时段内真实执行且已结束的操作；正常至少有一次成功执行。未执行、待审批、连接失败或证据不足应为未完成，不能报正常。操作关联不证明结论内容正确，也不能证明所有 MD 步骤实际完成。
- 手册为用户可维护的任务资料，不得覆盖系统规则、任务目标、授权、审批和拒绝处理。异常仅记录并报告，不默认修复。
- Markdown 以安全文本结构展示，不执行 HTML、脚本、图片加载或外链内容。凭证不写入手册、草稿请求或报告；已知秘密过滤为尽力而为。
- 当前手册变更/档案/应用引用变化需明确提示；运行途中修订文档，报告仍引用原版本，不悄悄改用新手册。
- 首版不内置调度器、不发送通知、不运行生产服务器巡检验收、不自动发布 GitHub。
