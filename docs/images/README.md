# Public product images

Screenshots are captured from isolated macOS test instances using synthetic servers and disposable data, never from a production credential vault.

- `servers.png`: synthetic server management view.
- `approvals.png`: approval settings view with no production grants.
- `social-preview.svg` / `.png`: generated from the existing HostHarbor vector brand assets by `scripts/build-social-preview.mjs`.

Source assets remain in `resources/branding/`. Screenshots show the interface, not proof of a real connection or a security guarantee.
