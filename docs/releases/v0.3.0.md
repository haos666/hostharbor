# HostHarbor v0.3.0

2026-11-20 · 代码更新 / Source update

## 中文

本次整合此前待合并的 v0.2.0 功能与后续本地迭代：凭证留在本机，每个智能体按独立接入获得服务器范围和审批策略，执行过程与结果可查看、回放。可选 AI 提供服务器上下文和清单建议；执行仍走同一个授权、审批、主机校验和记录入口。

### 主要变化

- **独立巡检模块**：位于服务器菜单下方，默认展示报告。清单以服务器识别，版本、最近状态和时间分列；新增时自动预填可编辑模板，保留手工输入和可选 AI 分析。服务器机器人只打开档案。
- **轻量清单、结构化报告**：AI 建议 3–6 项，移除重复目标、命令配额和虚假的逐条耗时预算；大日志先限制实际读取量。报告分为系统、应用、专项/自定义三区，可提交实际 CPU、内存和磁盘指标。五分钟是工作量参考，不是完成保证。
- **离线仪表盘与导出**：应用内阅读 Markdown，浏览器打开生成的离线 HTML；导出支持 Markdown、Word、HTML。默认深色、薄荷极光、科技网格、蓝紫星云提供完整布局、图表和背景；更换主题后重开或重新导出即可，无需重新巡检。
- **报告例外处理**：本次异常可忽略、撤销，报告有效状态重新计算，原始结果和证据保留。今后同类情况可由 AI 起草 50 字内补充说明，经用户编辑确认后追加到当前清单并产生新版本，不静默改写或扩大执行权限。
- **共享 SOCKS5**：集中创建代理，服务器选择引用；旧内联配置事务迁移，相同配置归拢。修改时原子更新关联服务器路径及版本，未完成请求和指纹挑战失效；在用代理禁止删除。认证继续引用本机密码凭证。
- **分类与批量选择**：自定义标签/颜色、多标签关联，最多四个快捷标签与完整下拉同步；修复轮询关闭下拉菜单。接入新建/编辑支持搜索和当前结果全选，保留范围外选择。私钥可通过直接路径导入，包括隐藏目录。
- **一致的桌面交互**：统一页面标题和锁定模板；操作结果使用不占布局的悬浮提示，成功自动收起、错误手动关闭；紧凑解锁/文件设置、修复上传开关，中英文同步。
- **承接 v0.2.0**：加密资产备份、选择性事务恢复、完整渠道审批、全局审批/拒绝与 MCP 输出分页续读。备份新增共享代理、标签和快捷偏好，恢复重映射引用并保留已有资产与同名本机标签偏好。

### 升级与边界

- v0.1.0 的 schema13 升级为 schema15，v0.2.0 数据仍为 schema15。升级前保留完整应用数据副本。相同 schema 编号不代表旧程序认识新增代理引用或元数据；回退需匹配的数据副本。
- 旧清单和缺少指标/分类的报告继续可读。未采集指标保持缺失，不填造零值、实时状态或历史趋势。
- 外部 MCP 客户端需重新连接刷新工具定义；可选 `section`、`subject`、`metrics` 位于报告 `items[]` 内，不在报告根层。指标引用同一检查项、本次成功执行的命令。原命令工具和数字输出游标保留兼容。
- 含新标签/代理字段的 `.hhbackup` 应使用本版或更新版本恢复；资产备份不包含完整本机设置、AI Key、MCP Token/授权、操作历史及巡检报告历史，不能替代完整数据回滚副本。
- 导出的报告为普通未加密文件，凭证库锁定不会撤回已保存文件或浏览器页面。仪表盘展示已保存的时间点结果，不是实时监控。
- 调度交给外部智能体，异常不自动修复。报告由智能体提交；引用校验不独立证明结论正确。任意 Shell 不保证安全/只读，未知远端结果不自动重试。

### 验证与分发

本地 `npm run check` 通过 978 项测试、类型检查和生产构建；已有 macOS arm64 原生 Core/OS 保护及合成 SSH/SFTP/MCP 验收、隔离双语 GUI 验收，覆盖巡检、导出、主题、代理、标签、悬浮提示及文件设置。发布候选再执行必要检查，arm64/x64 的最终验收与打包以发布 PR 的 CI 为准，不使用真实服务器。

源码合并与安装包发布分开。README 下载表保持指向已发布的 v0.1.0，新版安装包发布前不替换为无效链接。仅面向 macOS Intel 和 Apple Silicon，Windows 分发继续延期；二进制未完成 Developer ID 签名及公证。不包含内置调度、自动修复、自动更新或断点续传。

## English

This release consolidates the pending v0.2.0 batch and subsequent local development into a personal approval and monitoring workspace. Credentials stay local; each agent receives scoped MCP access and an independent policy. Optional AI supplies context and checklist suggestions, while execution retains shared authorization, host verification, approval and recording.

### Changes

- Dedicated report-first inspection workspace, server-based checklists, separate version/status/time columns, editable prefilled templates and reviewed optional AI analysis. The server robot opens its dossier only.
- Lightweight AI suggestions of 3–6 checks, byte-bounded log sampling and structured system/application/custom sections with optional actual CPU/memory/disk samples. Five minutes is a scope reference, not a deadline or command-time guarantee.
- In-app Markdown reading, offline browser dashboards and Markdown/Word/HTML export. Four complete themes change charts, layout and background while preserving saved facts; reopening an existing report applies the chosen style.
- Per-finding ignore/undo and effective-status recalculation without erasing original evidence. AI future-exception notes of up to 50 characters require review before appending a new checklist version; plans never silently change.
- Reusable SOCKS5 proxies with transactional legacy migration, reference guards, canonical route/revision updates and invalidation of unfinished operations/fingerprint challenges after edits.
- Colored tags, at most four optional quick filters synchronized with the complete dropdown/search, and a polling fix for native dropdowns. Agent server search/select-all-results and private-key path import include hidden directories.
- Shared page/locked layouts, floating feedback without content shifts, compact unlock/file settings and corrected switch geometry, in English and Chinese.
- Includes encrypted backup/selected restore, per-access policy/global controls and precise MCP output continuation from the previous batch. Proxy/tag definitions and references restore without overwriting existing assets or same-name local tag preferences.

### Upgrade and scope

v0.1.0 schema13 upgrades to schema15; v0.2.0 remains schema15. Preserve a complete pre-upgrade app-data copy: the same schema number does not guarantee older binaries understand new proxy references/metadata. Asset archives omit app/global secrets, MCP grants/Tokens, activity history and inspection reports, so they are not full rollback images. Use this version or newer for backups containing new tag/proxy fields.

Old checklists/reports remain readable and missing measurements stay unavailable. Reconnect MCP clients to refresh schemas. Optional `section`, `subject` and `metrics` belong inside `items[]`; metrics cite successful commands from the same item and inspection window. Existing command tools and numeric output cursors remain compatible.

Exports are unencrypted and remain readable after locking. Dashboards show saved point-in-time data, not live monitoring. Scheduling stays external, findings remain agent-authored, arbitrary shell execution is not guaranteed safe/read-only, and unknown outcomes are not retried automatically.

Local validation passed 978 tests/types/build, with prior macOS arm64 native Core/OS protection and isolated bilingual GUI coverage using synthetic data. The release PR rechecks the candidate and verifies/builds arm64/x64 packages; see final CI results. Source merge does not publish installers: README downloads continue to identify v0.1.0 until separate installer publication. Windows remains deferred; macOS binaries are unsigned/non-notarized, without a built-in scheduler, automatic repair/updater or resumable transfers.
