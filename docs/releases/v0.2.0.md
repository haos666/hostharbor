# HostHarbor v0.2.0

2026-11-04 · 代码更新 / Source update · [Tracking #3](https://github.com/haos666/hostharbor/issues/3)

## 中文

### 本次更新

- **加密备份与恢复**：独立密码保护 `.hhbackup`，导入前预览依赖、重复项及冲突，按选择事务新增，保留已有资产。备份包含当前巡检清单；不包含 MCP Token/授权、操作历史、巡检报告或全局秘密。[使用说明](../backup.md)
- **服务器巡检**：同一服务器窗口用 Tab 查看档案、巡检和报告。未保存时直接展示默认清单；AI 分析推荐简短检查步骤，预览、编辑、确认后保存。通过三个 MCP 工具获取清单及提交结构化报告，记录版本和操作引用。调度交给外部智能体，异常不自动修复；报告由智能体提交，平台不独立证明结论正确。[使用说明](../inspections.md)
- **渠道审批**：每个接入直接配置完整的命令、文件、风险规则与 AI 建议；系统设置仅保留“全部需要审批 / 拒绝所有执行”。全局拒绝优先，全局审批保留渠道拒绝。已有 Token 保持有效，修改只作废相关尚未派发的请求。[使用说明](../channel-approval.md)
- **输出分页修复**：`read_output` 明确每次最多八块，返回 `hasMore`、`outputComplete`、`outputAvailability`，沿同一操作和准确游标续读，不因分页重新执行命令。
- **交互与双语**：巡检编辑固定保存栏、AI 等待动画、报告分页与历史策略来源；中英文设置和渠道界面同步。

### 升级与兼容

存储版本从 v0.1.0 的 schema13 升至 schema15。升级前保留原数据目录副本；旧程序不能直接读取升级后的数据库，回退需使用匹配的数据副本。资产备份用于恢复资产，不包含完整的本机设置和历史记录。已有接入沿用原有效配置，不自动扩大权限。

MCP 增加巡检工具；外部客户端可能需要重新连接刷新工具目录。原命令工具和数字输出游标保持兼容。结果未知的操作不能自动重试，断开 SSH 不能证明远端进程已停止。

### 验证与分发

本地 939 项测试、类型检查和构建通过；macOS Apple Silicon 原生 Core、OS 保护、合成 SSH/SFTP/MCP 和中英文界面已验证。Intel 的本次更新由 macOS CI 再验证；Windows 安装包继续延期。没有用生产凭证或真实服务器做发布验收。

代码更新不等于已发布安装包。现有下载仍是 v0.1.0；新版双架构安装包应在 CI 验证后单独发布。应用仍未做 Developer ID 签名及公证。首次版本不增加自动更新、断点续传或内置巡检调度。

## English

### Changes

- **Encrypted asset backup and restore:** password-protected `.hhbackup` files, dependency/duplicate/conflict preview and selected transactional import while preserving existing assets. Current inspection plans are included; MCP grants/Tokens, activity history, inspection reports and global secrets are excluded.
- **Server inspections:** dossier/plan/report tabs, automatic unsaved templates, reviewed AI checklist suggestions and three scoped MCP plan/report tools. Reports retain plan versions and operation references. Scheduling stays external; anomalies are not automatically repaired. Agent-authored findings are not independently verified by the app.
- **Per-access approval:** full command/file/risk/advisory settings on each access profile. System settings contain only global required approval and denial switches. Denial has priority and required approval preserves channel denials. Existing Tokens remain valid; only affected undispatched requests are invalidated.
- **Output pagination:** the eight-chunk limit is per `read_output` call. Explicit successor/exhaustion/availability fields and exact cursor guidance continue the same operation without re-executing it.
- **Bilingual interaction improvements:** fixed save actions, AI waiting animation, paginated reports and recorded policy source.

### Upgrade and validation

Storage upgrades from schema13 to schema15. Preserve a pre-upgrade data-directory copy; older binaries cannot open the upgraded database and rollback requires matching data. Asset archives do not contain complete app settings or history. Existing access permissions are not automatically expanded.

Reconnect external MCP clients if their tool catalog needs refreshing. Existing command tools and numeric output cursors remain compatible. Unknown operations must not be automatically retried, and disconnecting SSH does not prove remote cancellation.

Local validation passed 939 tests, types/build, macOS arm64 native Core/OS protection/synthetic SSH/SFTP/MCP and bilingual GUI flows. Intel verification for this update runs in macOS CI; Windows distribution remains deferred. No production servers were used.

This source update does not publish installers. Existing downloads remain v0.1.0; new arm64/x64 installers require separate publication after CI. Binaries remain unsigned and non-notarized, with no automatic updater, resumable transfers or built-in inspection scheduler.
