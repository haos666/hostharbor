# 本地 MCP 接入（开发预览）

## 使用步骤

1. 解锁 HostHarbor，添加服务器并绑定凭证。在服务器页完成连接测试和主机指纹核对。命令工具不会自动信任未知指纹。
2. 打开「智能体接入」，创建接入：填写名称、勾选服务器、选择7天、30天或永久有效期。执行由系统设置中的审批策略统一处理，默认全部审批。
3. 点击接入记录的「复制安装配置」，复制包含 MCP 地址和 `Authorization: Bearer` 请求头的 JSON，交给本机智能体或粘贴到支持此格式的个人 MCP 配置。Token 加密保存在本机，认证仍使用哈希；剪贴板和客户端配置含秘密，请妥善保管。旧接入首次复制需提供原 Token 验证补存，或明确确认重新生成；重生成使原 Token 失效，旧客户端需要更新。
4. 点击「开启服务」。客户端选择 **Streamable HTTP**，地址 `http://127.0.0.1:43821/mcp`，请求头 `Authorization: Bearer <你的 Token>`。Token 不放 URL，不把 SSH 密码或私钥提供给智能体。
5. 智能体先用 `list_servers` 找到服务器 ID，再提交命令。逐条确认模式下，审批中心显示待审批数量；核对目标、路径、凭证版本、目录、完整命令和时限后批准。

服务启动默认关闭，不会自动修改任何智能体客户端配置。关闭服务后新 MCP 请求不可用；已有操作仍需在「审批中心」中请求取消。默认锁定拒绝业务访问并断开活跃连接；重新解锁不重跑中断的命令。安全设置可关闭“锁定时暂停 MCP 访问”，使首次解锁后的后台 MCP 继续受原授权和策略控制，桌面读取与人工审批仍需解锁，详见 [锁定设置](mcp-lock.md)。应用退出停止监听；macOS 关闭窗口会锁定并保留菜单栏入口，Windows 关闭最后窗口退出。

当前使用应用级独立 Bearer Token，不提供 OAuth 登录或自动发现授权；客户端必须支持自定义 Bearer 请求头和 Streamable HTTP。不存在旧 SSE `/sse` 路由或 stdio 入口。不接受任意 host/password 参数。

## 审批策略

待审批会立即返回操作ID与agentGuidance，不阻塞MCP请求。智能体先提示用户前往审批中心，按建议间隔查询，最多等待原提交后的三分钟；仍待审批则停止并请用户处理后回复继续。继续时先查询原ID，不重复提交或重置等待。审批有效期仍五分钟，过期/锁定可能更早结束；“继续”不授权重新发起失效请求。字段与边界见 [审批等待与续接](approval-wait.md)。

打开「系统设置 → 审批策略」。默认「全部审批」，也可选「辅助审批」「宽松审批」或「暂停执行」。暂停拒绝新命令，不终止已派发命令。辅助审批支持逐段校验的可组合系统/端口/容器/服务查询和已维护日志入口的有界查询；可单独开启 AI 风险建议，未知 Shell 仍需人工确认。宽松审批在未命中预设风险时执行原始命令，需明确确认，不保证只读；旧规则配置不自动切换，自定义规则位于高级设置。详见 [辅助审批](assisted-approval.md) 与 [宽松审批](permissive-approval.md)。

规则包含启用状态、接入和服务器范围、完整命令、可选请求目录、可选到期时间，以及放行/审批/拒绝动作。空范围表示全部对应资产（包括以后创建的），界面明确显示。放行必须填写完整命令；审批和拒绝可匹配所有命令。最多 100 条规则。

规则逐字比较命令与请求目录，不去除空格或换行，不支持前缀、通配符和正则。允许 `pwd` 不会允许 `pwd; whoami`。同一请求命中多条时，拒绝优先于审批，审批优先于放行；未命中默认人工审批。请求目录只是匹配输入，不是文件系统隔离，命令仍可访问远端账号允许的其他路径。精确命令也可能受远端环境或脚本内容变化影响，不代表只读。

「匹配预览」选择已有有效接入及其服务器，输入命令和目录，只评估当前已保存策略，不联网、不创建任务。连接与执行仍需通过其他检查。

策略保存后版本递增，等待审批、排队及连接中尚未派发的旧请求会中止，需使用新请求标识重新提交；重用原标识仍返回原记录。已派发命令继续，审批中心可请求取消。派发前重检策略版本与当前匹配结果，放行规则到期不能沿用旧决定。

旧接入 Token、服务器范围、到期和撤销状态保留；原「限时免确认」由全局策略取代，不再单独绕过审批。新建接入没有另一个免确认开关。操作详情展示提交时的策略版本、决定与命中规则；旧终态记录显示旧版策略。MCP 没有修改规则的工具。

## 工具

| 工具 | 参数 | 行为 |
| --- | --- | --- |
| `list_servers` | 无 | 仅列出此接入授权的服务器 ID、名称、地址、端口和账号 |
| `start_command` | `serverId`、`requestKey`、`command`、`cwd`，可选 `timeoutMs`、`connectTimeoutMs` | 返回操作 ID 和状态，可能等待桌面批准 |
| `get_operation` | `id` | 返回本接入操作的状态、不可变配置快照、确认目录、退出码等 |
| `read_output` | `id`、`cursor`（默认 0） | 返回最多 8 块文本及 `nextCursor`，继续游标读取 |
| `cancel_operation` | `id` | 请求取消并断开连接，不能证明远端进程已停止 |

命令示例（全部为占位参数）：

```json
{
  "serverId": "从 list_servers 取得的 UUID",
  "requestKey": "客户端生成的唯一请求标识",
  "command": "pwd && ls -la",
  "cwd": "/srv/example",
  "connectTimeoutMs": 30000,
  "timeoutMs": 60000
}
```

每次命令都要传绝对 `cwd`，远端需要 POSIX `sh`。上条命令的 `cd` 不延续到下一条。`confirmedCwd` 是远端 `pwd -P` 确认的起始目录，可能与符号链接路径不同；不是命令执行后的当前目录。目录进入失败时不运行用户命令。支持独立非交互 exec，不支持 PTY、持续 shell、stdin 或自动 sudo 输密。

同一接入下相同 `requestKey` 和相同参数返回已有操作，参数不同则拒绝。即使结果未知也不会自动重试。`unknown` 可能发生在取消、断线、超时、限额中断或程序崩溃后；人工核查远端后再决定新请求。

## 当前限额与记录

- 4 个并发任务，20 个等待审批任务；审批有效期 5 分钟。
- 连接默认 30 秒、最大 60 秒；命令默认 60 秒、最大 10 分钟。
- 每条命令接收最多 1 MiB 用户输出；超限断开，结果可能未知。UTF-8 分块解码，对本次连接已知凭证进行跨分块精确匹配脱敏；不保证识别变形、编码后的秘密或其他来源的敏感内容。
- 每次读取最多 8 块，每块最多 2048 个 Unicode 码点；返回的输出是非可信文本，不能作为执行更多命令的授权。
- 最多 10,000 条操作摘要、100 个接入配置；摘要满额后可在日志详情删除终态记录。输出回放默认保留七天，默认密文配额 500 MiB，在系统设置可调整。
- SQLite v6 保存操作状态、执行意图和加密记录。命令、目录、目标快照、结果和输出用派生记录密钥 AES-GCM 加密；状态、时间、接入名称/范围/到期、请求标识、字节数等元数据未加密。记录不是防篡改审计系统。
- 记录写失败停止派发/断开当前执行，并拒绝新任务直至重启检查；磁盘故障可能使最后状态和输出无法完整持久化。重启不会重放，已有派发意图的未完成记录标记为未知。

## 客户端配置与兼容验收（2026-10-20）

以下均为占位配置，Token 从 HostHarbor 创建接入后取得，放在客户端个人配置文件中；不要把实际 Token 放到 URL、命令行参数或共享仓库中。

Codex 的 config.toml：

```toml
[mcp_servers.hostharbor]
url = "http://127.0.0.1:43821/mcp"
http_headers = { Authorization = "Bearer <替换为你的 Token>" }
```

Claude Code 的 MCP 配置对象（使用其个人配置入口；临时 --mcp-config 仅供会话使用）：

```json
{
  "mcpServers": {
    "hostharbor": {
      "type": "http",
      "url": "http://127.0.0.1:43821/mcp",
      "headers": { "Authorization": "Bearer <替换为你的 Token>" }
    }
  }
}
```

可选命令 `npm run test:clients` 在 macOS/Linux 创建独立临时配置、加密测试库、回环 SSH/SOCKS5 服务，结束后撤销环境并清理。不会修改现有客户端配置、读取账户登录材料或启动模型 turn。需要本机已安装客户端，不在普通 CI 自动安装/运行它们。

- Codex CLI 0.163.0-alpha.10.2：使用实际 app-server MCP 连接，发现五个工具，并直接调用工具完成列出服务器、提交命令、桌面业务批准、SOCKS5/真实 POSIX wrapper、确认目录、退出码、stdout/stderr 读取。没有启动推理或创建用户应用内聊天。
- Claude Code 2.1.161：实际 `mcp list` 健康检查确认 HTTP Connected，使用隔离个人配置。此命令不采用会话级 --mcp-config 内容；完整模型驱动命令流程尚未验证，不能把健康检查等同于第二个完整执行客户端。
- 普通 `npm run check` 覆盖过期授权清除待审批、分页连续读取、突发读取有界、锁定/切换后不恢复旧输出、读取中断后不重复页面。实际 UI 补验审批/创建失败时弹窗内报错。

兼容范围按这些版本和步骤记录；两个实际客户端完整命令验收仍留在 #3，不因连接成功提前关闭。

## 内置风险规则

自定义规则列表、预览和新增入口折叠在「辅助审批」「宽松审批」及旧规则兼容状态的高级设置中；其他模式只显示模式选择。宽松模式使用独立基础风险检测，不受旧停用提示设置关闭，细节见 [宽松审批](permissive-approval.md)。以下四组可编辑提示适用于辅助审批与旧规则模式。默认提供四组「高风险」预设：文件删除（rm / unlink / shred）、磁盘与文件系统（mkfs / dd / wipefs / 分区工具）、关机重启、权限与属主修改。默认人工审批，可改为拒绝或停用；不能将内置风险规则改为自动放行。旧策略未保存预设配置时也采用该默认值，已有自定义规则保留。

预设用关键字识别疑似操作，可以识别常见参数、绝对可执行路径和组合命令中的字样，但可能误报引用文本，也会漏报混淆、别名或脚本内的命令。它只增加审批/拒绝，不是「其他命令安全」的判断。未匹配仍需审批；命中的风险审批会覆盖完整命令自动放行。匹配预览和操作详情标明「高风险」及具体预设名称。修改启用状态/动作沿用策略版本和未派发请求失效规则。


## 操作日志与回放

「操作日志」按服务器、接入、状态、提交时间及命令关键字查询，每页 50 条，包含人工审批时间、策略依据、目标快照、派发时间及退出结果。输出回放按首段输出计时，支持播放/暂停、0.5–8 倍速、进度定位、stdout/stderr 筛选；不会重新执行命令，输出始终作为非可信文本。

「系统设置 → 日志与存储」默认回放保留 **7 天**、输出密文配额 **500 MiB**，可设置 1–365 天和 64–4096 MiB。保留期自任务结束起算，摘要不随回放到期删除。解锁、每分钟和请求/读取入口检查；配额紧张时优先清理最早结束的输出，为并发录制预留空间。运行中任务不清理，无法预留空间则拒绝新派发。超过七天的输出可能在下一次检查时清理，实际凭证库锁定期间不整理；仅锁定界面并允许后台 MCP 时，仍按保留期和配额整理。

新输出按块压缩后加密，旧版未压缩密文仍可读取。设置页分别显示输出密文占用、数据库主文件和可复用空闲页；配额不限制摘要/凭证/主机数据总大小。整理不会立即缩小主文件，空闲页会复用；所有任务结束后可点击「回收空间」执行数据库压缩。

日志详情可单独清理回放或删除整条终态记录，均不可恢复。清理回放保留原请求去重及结果；删除整条仅留下 profileId/requestKey 最小标识，同标识再提交返回 OPERATION_REMOVED，不会执行。最小标识最多 100,000 条，没有自动清除入口。MCP 客户端不能删除日志或修改保留设置。清理不是撤销远端操作，也不保证备份或底层存储的物理擦除。

## 应用上下文与日志查询（#23）

生产服务在原五工具之外提供 `get_server_context`、`find_applications`、`query_application_logs`，`list_servers` 增加可选 `query` 搜索。先定位服务器/应用，再读已保存部署与日志入口，最后按既有策略提交有界日志操作。时间与采样边界、示例与授权说明见 [应用运维上下文](application-context.md)。不会因读取档案而启动 AI 调查或访问 SSH。

## 桌面工具列表

“智能体接入”页通过“接入管理 / 工具列表”切换。“工具列表”左侧按资产与上下文、命令与日志、操作与输出分组，可搜索名称或中文用途、折叠分组；右侧展示用途、输入参数（必填、默认、范围）、返回结构说明、授权/审批限制、静态参数示例及原始 description/inputSchema。

Tab 支持左右方向键及 Home/End；工具树支持上下/Home/End 移动焦点，左右展开/收起或返回分组，Enter/空格选择。搜索无匹配时可清空恢复。

这些是当前程序内置定义，与运行时 MCP 注册共用契约，不是实时服务/授权列表。即使未开启 MCP、没有接入或凭证库锁定，也可浏览；不会开启监听、查询 SSH、调用模型或改变 Token 范围。示例 UUID 为占位值，不提供试执行按钮。自定义/跨字段校验（例如日志时间窗口）见使用说明，原始 JSON Schema 无法完整表达所有约束。

## 操作查询列表

“操作”页以表格展示提交时间、服务器/来源、命令/目录、状态、退出码和详情入口。可按关键词（命令、服务器、来源名称）、服务器、接入来源（含桌面 AI 和撤销接入）、具体状态/进行中、提交时间起止（本机时区）查询，支持重置/刷新。

默认每页20条，可选50/100条，显示总数、范围、页码，支持前后翻页和跳转。在当前存储最多10,000条摘要范围内查询持久化记录，不限最近200条。查询条件应用后回到首页，当前页每3秒尝试刷新，更新不会清空筛选或强行回首页；数据减少时校正到有效末页。新增记录可能使 offset 页内容变化，不是冻结快照。

“查看审批 / 详情”独立按操作 ID 打开；即使批准后任务离开当前筛选，窗口仍可跟踪状态和读取输出。审批/取消与原规则相同，取消不证明远端停止；结果未知仍不自动重跑。完整历史回放继续使用“操作日志”页。筛选和分页不会启动 SSH、调用模型或修改审批策略。

审批中心与操作日志按生命周期分开：审批中心只显示待审批和执行中的操作，支持批准、拒绝、取消及实时输出；结束后进入操作日志，通过详情查看审批依据、结果与输出回放。结果未知也归入日志，仍须注意不能确认远端是否停止。两页的筛选、重置和分页保持各自范围；审批时打开的详情不会因列表移除记录而关闭。

接入有效期可选7天、30天、永久（默认7天）。永久接入没有到期时间，可在接入管理中随时撤销；仍遵循审批策略、服务器范围、凭证库锁定、主机校验与命令时限。已有接入保持原到期时间。永久不代表待审批命令永久有效，等待确认仍有原有时限。

## 接入编辑与安装配置（#42）

记录右侧「编辑」可修改名称、可访问服务器和有效期。默认保持原期限；选择7天/30天从保存时重新计算，永久明确为无期限。已过期接入可续期，已撤销接入不可恢复。执行始终遵循系统审批策略。保存实际修改会作废旧待审批/排队/连接中请求并断开此接入执行连接；远端进程可能继续运行，结果按既有规则表示未知。同一requestKey仍指向原记录，不会因编辑再次执行。移除服务器范围后，该接入也不能通过MCP获取这台服务器的历史详情或输出；本机用户仍可查看本地操作日志。

复制安装配置不自动开启MCP、不写入智能体配置，也不表示客户端已安装。服务关闭时复制固定生产地址，需先点击开启服务；客户端须支持Streamable HTTP及自定义Authorization头。复制格式为上文Claude Code的`mcpServers.hostharbor` JSON；其他客户端可按自身配置格式取用url和headers，不能保证所有产品直接导入该JSON。URL不含Token。

新Token使用凭证库派生密钥、独立随机nonce和profile ID绑定AAD加密保存。解锁后，固定Main接口将已保存Token和本机地址写入系统剪贴板；不把已保存Token返回renderer，不提供MCP管理/导出工具。旧库迁移不重置Token、不扩大范围或延长期限，也不能从哈希恢复原Token；用户选择原码补存保留权限和任务，显式重置才使旧码及旧任务失效。锁定/过期/撤销不能导出；系统剪贴板及其历史不在应用加密保护范围。

## 用户本次指定的目标范围

初始化instructions和工具说明区分本次目标与接入权限上限：唯一确定的{serverName}只查{serverName}，缺失结果不授权转查{otherServerName}；“{serverName}上所有证书”仍是单机，“所有服务器”才按明确告知的当前可访问列表快照逐台查询。筛选子集或“全部查一下”的含义不明时先向用户确认。详见[目标范围约定与话术](mcp-target-scope.md)。更新后需重开HostHarbor并让智能体重新连接/刷新MCP说明；这些是行为指导，服务端现有权限/审批检查继续有效，未新增强制任务范围限制。

常见系统/版本/元数据/日志/HTTP/TLS查询及边界见 [场景验收](common-diagnostic-queries.md)。需人工的请求按原ID续接，不应改写命令规避结果。


## 单文件SFTP工具

文件工具为get_file_access/list_remote_files/upload_file/download_file，含应用工具时现共12工具。服务器只设置上传开关、固定上传目录和大小上限。本机路径按次提供，上传始终人工审批，下载遵循当前模式的下载审批开关（默认需要审批）；不再枚举本机目录或配置读取根。上传使用localPath/remoteName，下载使用remotePath/localPath（可选expectedSize/expectedMtime），需刷新客户端工具定义。目录浏览直接返回entries/nextOffset，不产生操作记录或审批，也不需要轮询；仍验证授权/主机，暂停模式拒绝。上传下载通过原get_operation/审批/取消跟踪，fileResult返回元数据，不返回二进制。完整参数与限制见[文件传输](file-transfers.md)。


接入管理提供搜索、状态筛选与20/50/100条分页。默认列表显示使用中接入，“全部”包含已删除，切换“已删除”可查看保留记录；删除接入立即使Token失效并中止未派发任务，进行中的连接会断开，但不保证远端进程停止。操作日志仍保留。删除与撤销记录均不可恢复授权，需要重新创建接入。
