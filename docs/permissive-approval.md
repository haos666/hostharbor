# 宽松审批

系统设置提供全部审批、辅助审批、宽松审批、暂停执行。宽松审批是用户对日常运维的默认执行授权，不要求证明只读，也不依赖AI。

## 当前行为

- 自动执行：查询、修改配置、文件创建/覆盖、权限修改、安装更新、编译部署、应用/容器启停和重启、普通HTTP请求、下载解压、脚本与后台任务。变量、循环、重定向等不因语法本身转人工。
- 人工审批：识别出的删除/清空文件、账号删除、容器/镜像/卷删除或prune、带卷删除的compose down、软件卸载、git clean/reset --hard、设备擦除/格式化/分区修改、数据库删除清空、HTTP DELETE、整机重启/关机等。
- 区分systemctl restart <service>与systemctl reboot；前者日常运维可执行，后者人工。普通sudo使用同一判断，后台只使用已绑定的提权凭证；其他审批模式仍要求人工sudo。
- 自定义拒绝优先，其次人工审批；自定义放行不能覆盖命中的破坏性提示。既有明确的权限变更拒绝配置仍生效，默认权限修改不再人工。已知凭证值的尽力检测仍转人工。
- MCP文件上传/下载继续使用独立文件审批设置，SFTP不自动提权。

## 识别边界

不再将辅助审批的受限查询解析器用作宽松审批门槛。独立有界词法扫描尽力区分命令位置和文本参数，检查组合、命令替换、shell -c、eval和常见包装命令中的明确动作；echo/grep的删除文字及配置heredoc不直接当作删除命令。整条命令统一决定，不部分派发。

扫描不是Shell求值器或安全边界，不读取脚本文件、不解析任意语言、不访问远端做判断。外部脚本、下载后执行、动态命令名、别名、环境和远端服务可能实施未识别的删除等操作，仍按宽松授权执行；无法解析不会回退为“所有动态语法人工”。递归检查最多8层、累计64KiB，命令输入仍最多16384字符；超过提示分析预算不等于安全。

进入宽松模式仍要求明确选择确认；已有宽松模式随本版本采用上述日常运维语义，其他模式不自动切换。重启打断未结束任务，已保存历史审批依据不改写；当前派发仍复查目标/凭证/授权/策略快照和持久化意图。

服务器授权范围、到期/撤销、实际库锁定与后台MCP开关、主机验证、并发/超时、记录脱敏及不确定结果不自动重试保持。允许执行不代表只读或无破坏，录制不能撤销变更。

## 验证

合成测试覆盖普通写入/安装/重启/脚本/循环自动执行，删除与系统关机转人工、包装与命令替换、配置heredoc/标签避免误报、自定义规则、敏感值及宽松sudo。平台/真实客户端验收结果见执行计划；不自动访问真实资产。
